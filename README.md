# Information Legacy Framework (ILF) – Reproducibility Evidence

This repository contains supporting technical artefacts for the thesis:

**Operationalising Posthumous Digital Identity Governance:
A Design Science Proof-of-Concept for the Information Legacy Framework**

The repository supports the controlled synthetic evaluation of the
Information Legacy Framework (ILF).

## Contents

The repository includes:

- controlled synthetic CSV evidence files;
- module-level outputs for the six ILF modules;
- scenario-level evaluation outputs;
- Governance Effectiveness Index (GEI) results;
- validation outputs;
- sensitivity-analysis outputs;
- configuration and supporting reproducibility artefacts.

## Research boundary

All datasets contained in this repository are controlled synthetic data
generated for research purposes.

The repository does not contain:

- identifiable deceased-user information;
- live Online Social Network account data;
- proprietary platform information; or
- empirically observed platform-performance data.

The files support reproducibility, inspection and traceability of the
Design Science proof-of-concept evaluation described in the thesis.

## Reproducibility

The principal synthetic evaluation configuration uses:

- synthetic records: 1,200;
- scenario executions: 4,000 per scenario per analytical approach;
- fixed random seed: 20260316.

The repository should be interpreted within the validity boundaries
described in the thesis.
